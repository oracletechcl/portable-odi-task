# Spec Kit Migration Specs

🏠 [Delivery Home](../README.md) | 📚 [Migration Spec Index](./INDEX.md)

This family contains one GitHub Spec Kit feature folder per analyzed app.
Run `specify init` in a target project, copy these `specs/` folders and `.specify/` memory, then continue with `/speckit.plan`, `/speckit.tasks`, and `/speckit.implement`.

- Generated from the full introspector output tree.
- Each app's `deep-dive.md` is the first-class source of truth.
- No Red/Green evidence is fabricated.
- Compatible with the GitHub Spec Kit flow.
